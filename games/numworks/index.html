numworks games.

Games for the NumWorks graphing calculator. Plug yours in, pick some games and install them from this page.

  1. Update the calculator first if its software is older than version 26: numworks.com/calculator/update. On older software the games restart it, which erases everything on it.
  2. Plug your calculator into this computer with its USB cable.
  3. Click Connect calculator and choose NumWorks Calculator from the list.
  4. Pick your games, then install them. Keep it plugged in until it says done.
